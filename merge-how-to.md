Чтобы слить содержимое двух веток необходимо получить изменения веток с сервера git fetch, там можно посмотреть все ветки git branch --all, далее переключаемся в ту ветку, в которую хотим загрузить содержание другой git checkout "имя", объединяем ветки git merge "имя" ветки которую надо влить в ту ветку, в которой ты сейчас сидишь, отправить изменения на сервер git push. Таже можно посмотреть историю репозитория git log
