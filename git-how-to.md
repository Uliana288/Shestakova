#отправить ветку на сервер
Если ветка создана локально и её ещё нет на сервере (GitHub/GitLab/Bitbucket):

bash
Copy
git push -u origin имя_ветки
-u (или --set-upstream) связывает локальную ветку с удалённой, чтобы в дальнейшем можно было использовать просто git push.

origin — имя удалённого репозитория (по умолчанию).

имя_ветки — название вашей ветки (например, ivanov).

Пример:

bash
Copy
git push -u origin feature/login-form
2. Отправка изменений в существующую ветку
Если ветка уже есть на сервере и вы хотите отправить новые изменения:

bash
Copy
git push
Или явно указать ветку:

bash
Copy
git push origin имя_ветки
3. Если возникли конфликты
Если на сервере есть изменения, которых нет у вас локально:

Сначала подтяните изменения:

bash
Copy
git pull origin имя_ветки
Разрешите конфликты вручную (если они есть).

Затем отправьте изменения:

bash
Copy
git push
